One original line, 117 characters, roasting a gadget used every day — the phone's cloud storage. The program writes that line to `/output/entry.txt`: "My cloud storage is full, so my phone deletes my photos to make room for the update that tells me my storage is full."

## Why this line

The roast is a closed loop: the phone runs out of space, so it deletes your photos to make room for the update whose only job is to tell you that your storage is full. The fix is the problem, and the phone keeps reporting the problem it just caused. One sentence, no setup beyond the premise, and the punchline lands on the last words — which is what makes it read like a complaint a real phone owner would actually mutter.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
